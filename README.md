\# SmartPitaya 🍈



\## AI-Powered Dragon Fruit Disease Detection and Farmer Assistance System



SmartPitaya is an AI-powered web application designed to help dragon fruit farmers identify plant diseases from images and access useful farming-related information through a simple, farmer-friendly interface.



The system uses deep learning and computer vision with TensorFlow/Keras to analyze dragon fruit leaf and fruit images and predict supported disease categories.



\## Features



\- 🌿 Dragon fruit leaf disease detection

\- 🍎 Dragon fruit fruit disease detection

\- 🛒 Farmer marketplace

\- 🌦️ Weather information

\- 💰 Market price section

\- 👨‍🌾 Farmer-friendly user interface

\- 🤖 Deep-learning-based image classification



\## Machine Learning



The project uses transfer learning and deep learning for image classification.
